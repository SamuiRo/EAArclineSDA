# Arcline SDA

[English](README.md) · **Українська**

Кросплатформний (Windows і Linux) переписаний [Steam Desktop Authenticator](https://github.com/Jessecar96/SteamDesktopAuthenticator).
- maFiles за замовчуванням зашифровані.
- Підтвердження трейдів знову працюють після запуску Steam Trade Protection (липень 2025).
- Ядро можна підключати у власні програми.

Поточна версія: **2.5.0** ([CHANGELOG](docs/project/CHANGELOG.md)).

> Використовуйте на власний ризик. Хто має ваш maFile і пароль до нього, той контролює акаунт Steam. Обирайте сильний пароль і запишіть код відновлення (revocation code).

## Завантаження і запуск

1. Відкрийте [Releases](https://github.com/SamuiRo/EAArclineSDA/releases) і завантажте архів для своєї ОС:
   - Windows: `ArclineSDA-<версія>-win-x64.zip`
   - Linux: `ArclineSDA-<версія>-linux-x64.tar.gz`
2. За бажанням звірте архів із `SHA256SUMS.txt`.
3. Розпакуйте будь-куди й запустіть:
   - **ArclineSDA** — графічна програма;
   - **arcline-sda** — командний рядок.

Встановлювати .NET не потрібно: збірки самодостатні.

Примітки:
- **Windows:** SmartScreen може попередити про непідписану програму. Натисніть *Докладніше → Все одно запустити*.
- **Linux:** для іконки в треї потрібна підтримка StatusNotifier/AppIndicator. У GNOME для цього треба розширення AppIndicator; без нього програма теж працює.
- **Де лежить сховище:**
  - `%APPDATA%\ArclineSDA\vault` на Windows;
  - `~/.config/ArclineSDA/vault` на Linux;
  - папка `vault/` поруч із програмою (portable-режим);
  - будь-яке місце, задане через `--vault` або `$ARCLINE_SDA_VAULT`.

**Перехід зі старого SDA:** *File → Import old SDA folder* або `arcline-sda import-sda <папка>`. Зашифровані папки SDA теж підтримуються. Стару папку програма не змінює; видаліть її, коли переконаєтеся, що коди збігаються.

## Можливості

- **Коди Steam Guard** із синхронізацією часу зі Steam.
- **Підтвердження:**
  - чекбокси, *Select all* (Ctrl+A), *Accept / Deny selected*;
  - фільтр за типом (трейди / маркет / інше);
  - режим *All accounts*, що показує підтвердження всіх акаунтів разом;
  - **автопідтвердження для кожного акаунта окремо** (*Account → Auto-confirm…*): для кожного акаунта можна обрати трейди, лістинги на маркеті (продаж) і/або покупки, решта лишається ручною. Чутливі типи, як-от API-ключі чи зміна телефону, автоматично не підтверджуються ніколи.
- **Трей і автозапуск.** За бажанням програма стартує з Windows або при вході в систему одразу в трей і залишається там, коли вікно закрите. Опція *Unlock automatically on this PC* дає автопідтвердженню працювати одразу після старту (див. розділ «Безпека»).
- **Виправлення Trade Protection ([SDA #1111](https://github.com/Jessecar96/SteamDesktopAuthenticator/issues/1111)).** Steam відхиляє підтвердження трейдів, доки акаунт один раз не прийняв повідомлення у вебі. Старий SDA ігнорував цю відмову, тому кнопка *Confirm* мовчки нічого не робила. Arcline приймає повідомлення автоматично (`POST /trade/new/acknowledge`, той самий запит, що й popup у браузері; так само робить ArchiSteamFarm), повторює спробу один раз і показує підтвердження, які все одно не пройшли.
- **Шифрування за замовчуванням.** Режиму без шифрування немає.
  - Кожен maFile шифрується AES-256-GCM, ключ виводиться з пароля через PBKDF2-SHA256 (600k ітерацій).
  - Кожен файл самодостатній: для розшифрування не потрібен жоден manifest.
  - Записи атомарні, на Linux доступ до файлів лише у власника (`600`).
- **Сесії переживають перезапуск.** Access token оновлюється й зберігається, refresh token ротується. Якщо сесія все ж прострочилась, програма показує підказку «Log in again» замість потоку вікон.
- **Переїзд між ПК:** *Back up vault* (один зашифрований `.zip`) → *Restore from backup* на новому ПК, або злиття з уже наявним сховищем.
- **Експорт одного акаунта:**
  - зашифрований окремим паролем для передачі, або
  - plaintext у форматі SDA для разового імпорту в іншу програму (потім видаліть файл).
- **Додавання нового автентифікатора** до акаунта і його видалення.
- **Перенесення наявного автентифікатора** (наприклад, із застосунку Steam) в Arcline через SMS-код. Старий після цього перестає працювати.

## Безпека, чесно

Саме шифрування — не слабке місце. AES-256-GCM не зламано; атакувати можна лише пароль, перебираючи варіанти офлайн, а PBKDF2 робить кожну спробу дорогою. Отже, **захищає саме пароль.** Беріть 4–5 випадкових слів або 14+ символів.

Сіль і параметри KDF лежать відкрито, як і в будь-якій схемі з PBKDF2: сіль не є секретом. Вони прив'язані до шифротексту через автентифіковані дані GCM, тож їхню підміну буде виявлено.

*Unlock automatically on this PC* (за замовчуванням вимкнено) зберігає пароль у захищеному сховищі ОС: Windows DPAPI або keyring Linux (Secret Service) через `secret-tool`. Тоді будь-яка програма, запущена від вашого користувача ОС, зможе відкрити сховище на цьому ПК. Резервні копії та експортовані файли все одно вимагають пароль. Вмикайте, лише якщо потрібне автопідтвердження без вашої участі.

Від чого шифрування **не** захищає:
- шкідливе ПЗ на розблокованому ПК (кейлогери, читання пам'яті);
- plaintext-експорт, який ви забули видалити;
- слабкий пароль.

## Що де зберігається і як видалити

У папці програми лежить лише сама програма. Поза нею Arcline записує:

| Що | Windows | Linux |
|---|---|---|
| Сховище (ваші акаунти, зашифровані) | `%APPDATA%\ArclineSDA\vault` | `~/.config/ArclineSDA/vault` |
| Логи помилок | `%APPDATA%\ArclineSDA\logs` | `~/.config/ArclineSDA/logs` |
| Автозапуск (якщо ввімкнено) | `HKCU\…\CurrentVersion\Run\ArclineSDA` | `~/.config/autostart/arcline-sda.desktop` |
| Авторозблокування (якщо ввімкнено) | `%APPDATA%\ArclineSDA\autounlock.bin` (DPAPI) | запис у keyring `application=arcline-sda` |

Як видалити:
1. Виконайте *File → Remove app data from this PC* (або `arcline-sda cleanup`). Це прибирає все з таблиці, окрім сховища; за бажанням можна видалити й сховище. Заодно видаляються тимчасові файли, які лишали версії до 2.4.0 включно (`%TEMP%\.net\ArclineSDA`).
2. Видаліть папку програми.

Якщо акаунти ще можуть знадобитися, спершу зробіть резервну копію сховища.

## maFiles в інших програмах

| Як | Що використати |
|---|---|
| CLI | `arcline-sda decrypt file.maFile` виводить JSON у форматі SDA. Сховище не потрібне. |
| .NET | Бібліотека `Arcline.SteamGuard`: `MaFileVault.ReadExternalFile(path, passphrase)` |
| Python | `tools/mafile_decrypt.py` (`pip install cryptography`) |
| Будь-яка мова | Специфікація: [docs/features/MAFILE_FORMAT.md](docs/features/MAFILE_FORMAT.md). Лише стандартні примітиви: PBKDF2-SHA256 + AES-256-GCM. |

## CLI

```bash
arcline-sda init
```

```bash
arcline-sda confs myacc --json
```

```bash
arcline-sda accept myacc --all --type trade
```

```bash
arcline-sda export myacc --out myacc.enc.maFile
```

```bash
arcline-sda backup vault.zip
```

```bash
arcline-sda --help
```

Секрети ніколи не передаються аргументами. CLI бере їх із `--passphrase-file`, зі змінних `$ARCLINE_SDA_PASSPHRASE` / `$ARCLINE_SDA_TRANSFER_PASSPHRASE` або запитує.

Коди виходу:

| Код | Значення |
|---|---|
| 0 | Успіх |
| 1 | Помилка |
| 2 | Неправильні аргументи |
| 3 | Неправильний пароль |
| 4 | Сесія прострочена |

## Збірка з вихідного коду

Потрібен .NET 10 SDK.

```bash
dotnet test EAArclineSDA.slnx
```

```bash
dotnet run --project src/Arcline.SDA.Desktop
```

Тег `vX.Y.Z`, що збігається з `<Version>` у `Directory.Build.props`, запускає збірку релізних архівів у GitHub Actions. Документація проєкту (архітектура, рішення, roadmap) лежить у [docs/](docs/README.md).

## Стан

Код протоколу звірено з оригінальною реалізацією SteamAuth: коди й підписи підтверджень збігаються побайтно. Він покритий юніт-тестами проти фейкового Steam: trade protection, сесії, сховище, міграція, UI.

**Ще не перевірено на реальному акаунті Steam:** логін, прив'язка, підтвердження й видалення автентифікатора.
